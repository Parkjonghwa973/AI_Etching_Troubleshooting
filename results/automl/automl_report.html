9. 연구의 한계

  • 본 연구의 모든 데이터는 실제 장비 측정이 아닌 **교육용 합성 데이터**입니다. 생성 규칙 기반이므로 실제 공정의 물리·화학 현상을 완전히 대표하지 못합니다.
  • SHAP(또는 대체 설명 방법) 결과는 **모델 예측에 대한 설명**이며, 물리적 인과관계를 증명하지 않습니다.
  • AI 추천 공정 조건은 학습 데이터 분포와 탐색 범위 내의 후보일 뿐이며, 실제 장비 적용 시 반드시 엔지니어 검증이 필요합니다.
  • 식각 시뮬레이터는 합성 데이터 생성과 **동일한 가정**을 공유하므로, 시뮬레이터 검증은 독립적인 물리 검증이 아닙니다.
  • 최종 테스트셋 성능과 교차검증 성능은 다를 수 있습니다. 하이퍼파라미터 최적화가 항상 테스트셋 성능 향상을 보장하지 않습니다.
  • 이 프로젝트는 실제 반도체 장비를 제어하지 않습니다 (교육용 시뮬레이션 전용).
